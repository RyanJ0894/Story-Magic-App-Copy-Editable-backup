CURRENT SYSTEM OVERVIEW:

Story Magic is an AI-powered audio production pipeline that transforms film screenplays into professional cinematic audio with:
- AI-generated dialogue (ElevenLabs voices)
- Context-aware background music
- Scene-appropriate ambience
- Sound effects (SFX)
- Professional mixing with adaptive ducking
- EBU R128 loudness normalization

SYSTEM ARCHITECTURE:

1. User uploads screenplay PDF → Frontend (www.storymagicapp.net)
2. Frontend sends script to Supabase Edge Function: trigger-relevance
3. Edge function triggers RelevanceAI agent: "Ace, the AI Director"
4. RelevanceAI analyzes entire script and generates Director JSON with:
   - Scene-by-scene breakdown
   - Character dialogue with voice assignments
   - Music cues (track selection, timing, fade in/out)
   - Ambience cues (environment sounds, timing)
   - SFX cues (specific sound effects at timestamps)
5. RelevanceAI saves Director JSON to Supabase via: ai-director-callback edge function
6. Frontend polls Supabase for Director JSON
7. Once found, frontend calls Railway orchestrator: https://web-production-7c7a9.up.railway.app/orchestrate
8. Railway processes ENTIRE Director JSON:
   - Generates TTS for ALL dialogue lines
   - Selects music/ambience from catalog based on mood/intensity
   - Builds timeline with ALL audio events
   - Mixes with adaptive ducking (music lowers when dialogue plays)
   - Normalizes loudness to -16 LUFS
   - Concatenates ALL scenes with crossfades
   - Uploads final episode.m4a to Supabase Storage
9. Frontend receives public URL and plays complete audio

WHAT IT'S SUPPOSED TO DO:

For a 3-page screenplay with multiple scenes:
- Generate 5-10 minutes of complete audio
- Include ALL dialogue from ALL scenes
- Play background music throughout (selected based on scene mood: tense, romantic, action, etc.)
- Layer ambience under dialogue (medical tent sounds, forest ambience, city street noise, etc.)
- Insert SFX at specific moments (door slam, gunshot, phone ring, etc.)
- Professional mixing where music automatically ducks (lowers volume) when characters speak
- Smooth transitions between scenes
